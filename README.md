# homebrew-tap

Homebrew formulae for jonasbg's tools, for macOS and Linux.

```sh
brew install jonasbg/tap/ted   # fast native code editor opened from the terminal
brew install jonasbg/tap/wex   # extract a web page's readable content as Markdown
```

| Formula | Source |
| --- | --- |
| `ted` | [jonasbg/ted](https://github.com/jonasbg/ted) |
| `wex` | [jonasbg/wex](https://github.com/jonasbg/wex) |

The formulae are written by each project's release workflow; don't edit them
by hand. On macOS, ted's app bundle is at `$(brew --prefix ted)/ted.app`.
